# Power-BI

###  Project Objective

The objective of this project is to analyze food delivery and restaurant operational data using Microsoft Power BI to evaluate business performance, monitor key performance indicators (KPIs), and generate actionable business insights. The project focuses on analyzing order trends, restaurant performance, revenue generation, customer behavior, delivery efficiency, and payment transactions to understand operational performance and identify opportunities for improvement.Power BI is used for data modeling, DAX calculations, and performance monitoring, enabling stakeholders to evaluate business trends and make data-driven decisions to improve customer experience, delivery performance, and overall business growth.

### 🗂️ Dataset and Tables

The project uses the food_delivery_db MySQL database, containing seven tables as follows<br>
| Table                     | Description            |
|---------------------------|------------------------|
| Customers                 | Customer details       |
| Restaurants               | Restaurant information |
| Menu_items                | Menu items, categories, and prices |
| Delivery_partners         | Delivery partner details |
| Orders                    | Order status and delivery information |
| Order_items               | Items and quantities in each order |
| Payments                  | Payment methods and details |
